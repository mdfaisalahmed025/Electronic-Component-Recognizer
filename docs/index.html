Welcome to the Component Recognizer

This project identifies 20 different electronic components using AI-powered image classification.

📌 About This Project

This project is an end-to-end pipeline for building an image classification system that can recognize and classify electronic components. It covers the entire workflow — from data collection, data cleaning, training, evaluation, and deployment to API integration with a live demo.

The model is designed to classify 20 different types of commonly used electronic components in circuits, prototyping, and hardware systems.

📊 Dataset

The dataset was collected from the web using DuckDuckGo search results and cleaned using fastai’s ImageClassifierCleaner. After several iterations and fine-tuning a ResNet34 model, the system achieved ~97% validation accuracy.

ℹ️ About This Project

This project is built with fastai and PyTorch for training, and deployed with Gradio on Hugging Face Spaces. The goal is to help students, hobbyists, and engineers quickly recognize electronic components.
